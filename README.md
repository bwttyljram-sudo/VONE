# بوت VONE — تحويل نص إلى صوت (أصوات عربية مجانية)

## الملفات
- `bot.py` — الملف الأساسي، يشغّل البوت والسيرفر الوهمي معاً.
- `server.py` — سيرفر Flask بسيط يبقي خدمة Render نشطة (health check فقط).
- `database.py` — قاعدة بيانات SQLite (مستخدمين، مفضّلة، سجل طلبات).
- `voices.py` — قائمة الأصوات العربية الـ32 المتاحة من Edge TTS.
- `keyboards.py` — بناء كل الأزرار.
- `config.py` — كل الإعدادات تُقرأ من متغيرات البيئة.
- `requirements.txt` — المكتبات المطلوبة.

## النشر على Render (خطوة بخطوة)

1. ارفع هذا المجلد إلى مستودع GitHub جديد.
2. من لوحة Render: **New → Web Service** واربطه بالمستودع.
3. **Build Command:** `pip install -r requirements.txt`
4. **Start Command:** `python bot.py`
5. من تبويب **Environment**، أضف المتغيرات التالية:
   - `BOT_TOKEN` = توكن البوت من BotFather
   - `ADMIN_ID` = `6043858925` (أو عدّله لآيديك)
   - `CHANNEL_USERNAME` = `@ZenoX_Tools`
   - `CHANNEL_LINK` = `https://t.me/ZenoX_Tools`
6. **مهم جداً:** أضف البوت كـ **أدمن** داخل قناة `ZenoX_Tools`، وإلا فلن يستطيع التحقق من اشتراك المستخدمين (خطأ `get_chat_member`).
7. اضغط Deploy. بعد التشغيل الأول ستُنشأ قاعدة بيانات SQLite تلقائياً بجانب الكود.

> ملاحظة: قرص Render المجاني غير دائم (Ephemeral) — عند كل إعادة نشر (Deploy) تُفقد قاعدة البيانات المحلية.
> إذا أردت الاحتفاظ بالمستخدمين والإحصائيات بشكل دائم، أضف لاحقاً **Render Disk** مدفوع أو انقل `database.py` إلى قاعدة بيانات خارجية (مثل PostgreSQL المجانية من Render نفسها).

## أوامر الأدمن (نصية، من داخل الخاص مع البوت)
- `إحصائيات` → يعرض إحصائيات حيّة مع زر تحديث 🔄
- `إذاعة` → يفعّل وضع الإذاعة، ثم أي رسالة تالية ترسلها تُبث لكل المستخدمين ببطء وأمان

## حدود الحماية (قابلة للتعديل من `config.py`)
- `MAX_CONCURRENT_TTS = 5` — أقصى عدد تحويلات متزامنة في نفس اللحظة.
- `PER_USER_COOLDOWN_SECONDS = 3` — أقل فاصل زمني بين طلبين لنفس المستخدم.
- `MAX_TEXT_LENGTH = 2000` — أقصى عدد أحرف للنص الواحد.
- `BROADCAST_DELAY_SECONDS = 0.05` — تأخير بين كل رسالة إذاعة وأخرى.

## ملاحظة صادقة حول الإحصائيات
تيليجرام لا يوفّر "دولة" حقيقية للمستخدم عبر الـ API، ولا وسيلة لسحب كل حالات
اشتراك القناة دفعة واحدة لآلاف المستخدمين دون تجاوز حدود الطلبات. لذلك:
- "أبرز الدول" في الإحصائيات تم استبدالها بـ **لغة تطبيق تيليجرام** لدى المستخدم، وهي أقرب تقريب متاح.
- "عدد المشتركين بالقناة" يُحسب بحسب **آخر تحقق فعلي** جرى لكل مستخدم (عند إرسال /start أو ضغط زر تحقق)، وليس فحصاً حيّاً لحظياً لكل المستخدمين.
